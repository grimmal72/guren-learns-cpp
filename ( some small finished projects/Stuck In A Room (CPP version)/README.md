This is a C++ translation of a Twine game I made in like 2022. This is a continuation of me scraping the bottom of the barrel of old code projects that I made in the past that I want to translate to C++.

Here is the original Twine version, hosted on my Neocities website: https://jordanislame.com/pages/gamesofmine/stuckinaroom.html

I think that the skeleton of the C++ version will be useful, as it is a certain style of visual novel, that is like a Choose-Your-Own-Adventure novel.
I think that structurally, it is like the Super Mario Brothers 2 Choose-Your-Own-Adventure book by Scholastic.

While my Haunted Mansion game has a 4-direction cardinal NSWE map system like Zork, this Stuck In A Room game functions more like Snatcher or something, where the dialogue and mental thought processes control
the menu options, instead of cardinal directionality.

Two different useful text adventure / visual novel concepts.

Anyways, I think that the skeleton of this game will be useful to hold onto.

There was a story to this game originally I guess but it was basically The Shawshank Redemption. It'll probably never be expanded.
